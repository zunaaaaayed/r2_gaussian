# Literature evidence matrix — inspected 2026-10-05

This is a targeted review, not a systematic novelty search. “Unknown” means not
verified in the inspected material, never that an experiment or capability is
absent. Full-text sections below were inspected for specific questions; supplements
and implementations have not all been audited. No proposed regularizer is novel
merely because this repository does not contain it.

## Research decision

Geometry-conditioned Gaussian initialization/refinement, directional TV and
physics-constrained learned priors all have close prior art. A defensible project
contribution would need a precise, validated rule and fair evidence that it
transfers across reserved acquisition conditions and independent volumes. None
of that is established by the pilot or this matrix. Resolve SPARK full text first
for a novelty claim; continue benchmark preparation independently.
